# Evaluation — awareness, not hearing restoration

This page is for a funder or a clinic. A first-time user does not need it. Start at [START_HERE.md](../START_HERE.md).

Health Innovation NENC (September 2026) said the remaining job is evidence that this implementation delivers meaningful benefit in real use. This is the smallest study that answers that, without claiming treatment.

## What is being measured

Whether a wearer can tell which class of sound happened, from a wrist pattern, in ordinary rooms.

Classes only:

- voice present (not what was said)
- doorbell or chime
- alarm or siren
- animal
- traffic or vehicle warning
- television, radio, or other media
- silence / no significant event

## What is not being measured

- Speech understanding.
- Aided thresholds.
- Tinnitus change.
- Replacement of a hearing aid or a cochlear implant.

## Record, per session

- Event class the system reported.
- Event class the wearer named from the pattern.
- Missed events the wearer later confirmed.
- False alerts.
- Whether the pattern was learnable after a short familiarisation, and after a week.

A result is a count of hits, misses, and false alerts. It is not a clinical claim.

OpenHear remains an environmental sound awareness tool. It is not a medical device.
